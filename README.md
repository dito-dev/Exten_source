# Dito Extensions Source

Extension repository for [Mangayomi](https://github.com/kodjodevf/mangayomi).

---

## 📦 Quick Installation / Add Repository Link

Copy the URL below and paste it into the **Add Repository** section in your Mangayomi settings:

```
https://raw.githubusercontent.com/dito-dev/Exten_source/main/anime_index.json
```

or:

```
https://raw.githubusercontent.com/dito-dev/Exten_source/main/index.json
```

## 🛠️ Features & Details

- **Direct 1080p Streaming**: Direct full-duration video streams without ads or preview loops.
- **REST API + DOM Hybrid**: High-speed catalog loading with tag/category filters.
- **Multi-Episode Support**: Full extraction of all episodes on single-page series.
